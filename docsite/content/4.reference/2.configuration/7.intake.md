---
title: Intake
description: "Every field in intake.yaml: autonomous pickup."
---

`intake.yaml` controls whether Kraft picks up work on its own.

Off by default. When enabled, Kraft polls [`bd ready`](https://github.com/gastownhall/beads),
the ready list of the optional [beads](/concepts/vocabulary#beads) issue tracker,
and files each matching issue as a paused work item without anyone typing
`kraft item create`. Like every other [intake](/concepts/vocabulary#intake) path,
the item lands paused with no gate skipped.

```yaml
enabled: false
interval_s: 300
repos: []              # empty means every enabled repo in repos.yaml
priority_ceiling: 2    # P0 and P1 are left for a person; P2 and higher numbers are picked up
```

| Field | Default | Means |
|---|---|---|
| `enabled` | `false` | Turns autonomous pickup on. |
| `interval_s` | `300` | Seconds between polls. |
| `repos` | `[]` | Repo paths to poll. Empty means every enabled repo in `repos.yaml`. |
| `priority_ceiling` | `2` | Issues with a priority number below this (P0, P1) are left for a person. P2 and higher numbers start unattended. |
| `max_concurrent` | `3` | Superseded by `max_concurrent` in [`policy.yaml`](/reference/configuration/policy). A value set here is used only when `policy.yaml` does not have the key. |

An item that auto-intake files lands paused like any other. After it starts, it
stops at its first gate for a human exactly as a typed-in one does. Auto-intake
removes the typing, not the judgement. Editable here or from Settings → Auto-intake,
which applies a change without a restart.
