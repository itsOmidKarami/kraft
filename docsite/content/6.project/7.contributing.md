This page covers the path to a first change: fork, set up, test, open a pull
request. The contributor guide in the repository is the single source for it,
so it can't drift from the code:
[Your first pull request](https://github.com/itsOmidKarami/kraft/blob/main/CONTRIBUTING.md#your-first-pull-request).
Maintainers cut releases as [RELEASING.md](https://github.com/itsOmidKarami/kraft/blob/main/RELEASING.md) describes.
