first, then How a work item runs.

## In this section

- [Vocabulary](/concepts/vocabulary): what each Kraft term means, from work item, chain, node, task, gate, and cap to harness, sandbox, and worktree. Start here.
- [How a work item runs](/concepts/how-a-work-item-runs): the lifecycle from filing to archive, and where steers, fix loops, and escalation fit. Read second.
- [Caps and budgets](/concepts/caps-and-budgets): how Kraft bounds time, tokens, and dollars. Read it when you set limits, or when a cap stops an item.
- [Why a permission gate](/concepts/permission-gate): why Kraft answers a worker's permission prompts itself. Read it when you restrict a worker's tools.
