Three guides cover the care of a Kraft install. This page holds what is true
before you use any of them, and how to restart the server safely.

- [Back up and restore the database](/guides/run/back-up-and-restore): copy the database while the server runs, restore it, and use the copy Kraft makes before an upgrade.
- [Logs and disk space](/guides/run/logs-and-disk-space): find the logs, and reclaim the space worktrees use.
- [Run Kraft as a service](/guides/run/run-as-a-service): start Kraft at login, and run a second instance.

## Before you start

- Everything these guides touch lives under `$KRAFT_HOME`, which is `~/.kraft` unless you
  set it. `run/` holds the state, `config/` holds the YAML you edit. See
  [Data and privacy](/project/data-and-privacy#secrets-and-state) for what each
  file holds.
- The commands assume the default home. Put your own path in place of
  `~/.kraft` if you moved it.

## A restart ends running agents

Stopping Kraft stops every agent it is running. That holds for
`kraft admin stop`, `kraft admin restart`, `kraft admin update --restart`, and a
restart of the [service](/guides/run/run-as-a-service#run-kraft-as-a-service).
When Kraft starts again, each item whose agent was running stops with
`reattach: running session, PID identity unconfirmed, no result (pid N is not alive)`,
and the board shows it as failed.

To restart without ending an agent, restart when nothing is running, or pause the
running items first and resume them afterwards:

1. List the items that may have an agent running:

   ```bash
   kraft view list --all --status=active
   ```

2. Pause each of them: `kraft item pause ID`.
3. Restart the server: `kraft admin restart`, or `kraft admin update --restart`
   when you are also updating.
4. Resume each item you paused: `kraft item resume ID`.

`kraft admin restart` and `kraft admin update --restart` list the active items
first and, in a terminal, ask before going on (`-y` skips the question).
`kraft admin stop` only lists them.

You know it worked when `kraft view list --all --status=active` lists the items
you resumed.

An item that a restart already stopped needs only `kraft item retry ID`.
