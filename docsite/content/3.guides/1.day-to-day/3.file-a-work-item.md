---
title: File a work item
description: File a work item from the board's composer, or from the full new-item page, and choose its chain and documents.
---

A work item is filed from the web UI with a composer on the board, or with the full page it opens. This page lists the composer's fields and what **Create paused** does.

**+ New work item**, at the top right of the board, opens a composer at the
top of the list:

- **Title**, and a line of brief that every node reads.
- The **repo** and the **chain**, each a menu. The repo menu lists only
  enabled repos; with none, the composer says so, links **Settings ›
  Repos**, and creates nothing. The chain menu shows each chain's node and
  gate count, and marks the repo's default.
- **+ spec** and **+ plan** attach a document: search the repo's specs or
  plans, or paste a path relative to the repo. The file must be inside the
  repo, since it is committed on the item's branch: copy one kept elsewhere
  into the repo first, for example to `.engineering/specs/`. A chain that starts by writing
  a spec or a plan skips that node and its gate when you attach one.
- **N of N nodes run · N gates** says what will run, as the server works it
  out from what you attached.

**Create paused** files the item without starting it, so nothing spends
tokens until you start it from [the side panel](/reference/web-ui/board#the-side-panel). The **▾** beside it holds
**Create and start**. **⌘↵** (**Ctrl+Enter**) also creates and starts.

**More options ⤢** carries the draft to the full new-item page at
`/work-items/new`. It adds:

- a larger brief;
- **Start from existing** with the **+ spec** and **+ plan** slots;
- the chain drawn as a graph.

Click a node to look at it or skip it for this item, and set overrides for this
item alone in [the inspector](/reference/web-ui/item-page#the-inspector)'s **Config** tab.

Its **Create paused ▾** works the same way. Nothing is created until you click
it, and **Cancel** discards the draft.
