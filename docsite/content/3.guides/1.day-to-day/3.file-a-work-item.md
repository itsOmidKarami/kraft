---
title: File a work item
description: File a work item from the board's composer, or from the full new-item page, and choose its chain and documents.
---

A new work item is filed paused, so nothing spends tokens until you start it.

## Before you start

- A connected, enabled repo. The composer lists only enabled repos. See
  [The setup wizard on first start](/guides/day-to-day/first-run) to connect one.
- Optionally, a spec or plan to attach, inside the repo.

## File an item from the composer

1. Click **+ New work item**, at the top right of the board. A composer opens at
   the top of the list.
2. Write the **Title**, and a line of brief that every node reads.

   ![The board's composer open above the list, filled in: the title Cache the schema lookups, a line of brief, the kraft-plugins repo and default chain menus, + spec and + plan, a line counting 15 of 15 nodes run and 5 gates, and Create paused, with Created paused, nothing spends tokens until you start it](/assets/composer.png)

3. Pick the **repo** and the **chain**, each a menu.
   - The repo menu lists only enabled repos. With none, the composer says so,
     links **Settings › Repos**, and creates nothing.
   - The chain menu shows each chain's node and gate count, and marks the
     repo's default. Of the [repo libraries](/reference/configuration/repo-libraries),
     it lists only the chosen repo's own: another repo's chains are not offered.
4. Optionally, click **+ spec** or **+ plan** to attach a document: search the
   repo's specs or plans, or paste a path relative to the repo.
   - The file must be inside the repo, since it is committed on the item's
     branch. Copy one kept elsewhere into the repo first, for example to
     `.engineering/specs/`.
   - A chain that starts by writing a spec or a plan skips that node and its
     gate when you attach one.
5. Read **N of N nodes run · N gates**. It says what will run, as the server
   works it out from what you attached.
6. Click **Create paused**. It files the item without starting it. While the title is empty the button is off and the line beside it says why; **⌘↵** on an empty title moves you to the title field.

## Create and start in one step

The **▾** beside **Create paused** holds **Create and start**. **⌘↵**
(**Ctrl+Enter**) creates paused, like the button. On a phone, **Create paused**
is the main button and **Create and start** sits beside it.

The composer keeps your draft across a reload, and drops its repo if that
repo has been disconnected since.

## Use the full page

![The full new-item page: the title Cache the schema lookups, the brief, the repo, + spec and + plan, Comes after, and the default chain drawn as a graph with the pane saying 15 of 15 nodes run and that it starts paused, under Cancel and Create paused](/assets/new-item-page.png)

**More options ⤢** carries the draft to the full new-item page at
`/work-items/new`. It adds:

- a larger brief;
- **Start from existing** with the **+ spec** and **+ plan** slots;
- **Comes after** with **+ item**, to pick unfinished items this one waits
  for: started before they complete, it is [blocked](/reference/statuses)
  until they do;
- the chain drawn as a graph, a long one with
  [the chain overview](/reference/web-ui/item-page#the-chain-overview) above it.

Click a node to look at it or skip it for this item, and set overrides for this
item alone in [the inspector](/reference/web-ui/item-page#the-inspector)'s
**Config** tab.

The page's **Create paused ▾** works the same way. Nothing is created until you
click it, and **Cancel** discards the draft.

## File with a one-off chain
_Added in next_

A one-off chain belongs to one item. It extends a library chain, adds or changes
what this item needs, and never joins the library. File one two ways:

- On [the full page](#use-the-full-page), open the chain menu and pick
  **Customize for this item**. The canvas is the Templates editor's: a **+** on a
  connector adds a library node or a **Custom agent node** with your own prompt,
  and the **YAML** tab edits everything else, such as removing a node or
  overriding a field. Nodes with custom content have a dashed ring. **Create
  paused** stays off while the chain has problems. **Back to** the base chain
  drops the customization.
- From a terminal, `kraft item create "title" --chain-file chain.yaml`. An agent
  files one through the MCP tool the same way.

An item with custom content, such as an added node's prompt, never starts until a
person has approved exactly that chain. On the page, **Create paused** and
**Create and start** open a review, **Approve and create**, before the item is
filed. Otherwise **Start** opens
[the review](/reference/web-ui/config-before-start#reviewing-a-one-off-chain) in
the web UI or the phone. A one-off chain that only uses library parts needs no
review, unless a library node sits after the final approval gate.

The review stops an MCP session or a worker from starting custom content on its
own, and it records who approved and through which door. It does not prove that a
person was at the keyboard: a command run from a local shell reads as a person.

## Check it worked

The item you filed with **Create paused** appears on the board under **Not started**. Start it from
[the side panel](/reference/web-ui/board#the-side-panel) when you are ready.
