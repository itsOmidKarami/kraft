title: Remote access
description: Approve or reject a gate from a phone, over a tunnel, using the same password auth as the local board.
---


Reach the Kraft board from a phone or another machine by putting a tunnel in
front of the server and turning on password auth. You need a password, an
`allowed_hosts` entry for the tunnel's hostname, and a non-loopback bind.

## Why the server must bind off loopback

By default Kraft binds `127.0.0.1` and skips auth for local clients. A tunnel
client running on the same machine looks local, so on a loopback bind it
would reach the board with no password. A browser reaching a loopback bind
through the tunnel also fails: the Host header carries the tunnel's name, which
a loopback bind refuses.

A non-loopback bind fixes both. Kraft then requires the password from every
client and checks browser Host headers against `allowed_hosts`. The cost is
that the server also listens on your other network interfaces, such as your
LAN, where the password is the only barrier. A tunnel that connects to
`localhost` needs `0.0.0.0` or another address that includes loopback. If your
LAN is untrusted, block the port at your firewall for other interfaces.

## Set up a tunnel

1. Set a password in Settings → Access while you are still on `127.0.0.1`.
   `kraft admin start` refuses a non-loopback bind without one.
2. Add the tunnel's hostname to `allowed_hosts` in `access.yaml`, through
   Settings → Access or by hand. Run `kraft admin doctor` to confirm the file
   parses. For Cloudflare Quick Tunnel, you learn the hostname in step 4, so
   come back to this step then and restart.
3. Start the server off loopback:

   ```bash
   kraft admin start --host 0.0.0.0
   ```

   The port is 8765 unless you set `port` in `access.yaml` or pass `--port`.
   Use your port wherever this page says 8765.
4. Point a tunnel at the port:
    - **Tailscale**: run `tailscale serve --bg 8765`, which proxies your
      tailnet's HTTPS address to the local port. The `serve` options differ
      between Tailscale versions, so check `tailscale serve --help` for yours.
      Your `allowed_hosts` entry is the machine's tailnet name, such as
      `mybox.tailnet-name.ts.net`.
    - **Cloudflare Quick Tunnel**: run
      `cloudflared tunnel --url http://localhost:8765`. It prints a
      `*.trycloudflare.com` URL. Add that hostname to `allowed_hosts` and
      restart the server before you use it.

## Verify the tunnel

1. From the phone or other machine, request the health endpoint, which needs
   no login:

   ```bash
   curl -s https://<your-tunnel-hostname>/api/health
   ```

   A JSON status confirms the tunnel reaches Kraft.
2. Open `https://<your-tunnel-hostname>/` in a browser. You should see the
   login page. Log in with your password.
3. If the browser shows a 403 with "unexpected Host", the hostname is missing
   from `allowed_hosts`. Add it and restart the server.
