Install Kraft, then run a work item through its gates to a merge-ready diff.
New here? Do these two, in order.

## In this section

1. [Install](/get-started/install): install Kraft with uv, Homebrew, the install script, or from source, start the server, and register it with Claude Code.
2. [Your first work item](/get-started/first-work-item): connect a repo, run a work item end to end, and approve its gates.

Also here:

- [Why Kraft](/get-started/why-kraft): what it does that a session, a loop or a skill does not, and when not to use it. Read it first if you are still deciding.
- [Troubleshooting and FAQ](/troubleshooting): why an item stopped and how to restart it, doctor failures, and common questions.
- [What's new in 2.0](/guides/run/whats-new): the new interface, code-host review, a repo connect that reads more of the repo, and what to check before you upgrade from 1.4.
