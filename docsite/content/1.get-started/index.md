Want to see the interface first? Open the [demo](/demo/). Still deciding
whether Kraft is for you? Read [Why Kraft](/get-started/why-kraft) and the
[FAQ](/get-started/faq). Ready to try it? [Install](/get-started/install)
Kraft, then run [your first work item](/get-started/first-work-item), and after
it [the real chain](/get-started/the-real-chain) through its gates to a merged
pull request. If something goes wrong, see
[Troubleshooting](/troubleshooting). To upgrade from 1.4, see
[Upgrade from 1.4](/guides/run/upgrade-from-1-4), and
[What's new in 2.0](/project/whats-new) for what changed.

## In this section

- [Why Kraft](/get-started/why-kraft): what it does that a session, a loop or a skill does not, and when not to use it.
- [Install](/get-started/install): install Kraft with uv, Homebrew, the install script, or from source, start the server, and register it with Claude Code.
- [Your first work item](/get-started/first-work-item): part 1 of 2: connect a repo and run a work item end to end on the quick-task chain.
- [The real chain](/get-started/the-real-chain): part 2 of 2: run the default chain, approve its gates, and review the change to a merged pull request.
- [FAQ](/get-started/faq): short answers on what Kraft works with, what it costs, and how to write a spec.
