Kraft's web UI is the server's own page: start `kraft` and open `http://127.0.0.1:8765`. These pages name each screen and the buttons on it.

## In this section

- [The board](/reference/web-ui/board): the groups, a row's button, the filters, selecting several items, archived items and the side panel.
- [An item's page](/reference/web-ui/item-page): the header's actions, the chain graph and the inspector.
- [The review page](/reference/web-ui/review-page): Compare, Viewed, commenting on a line, Finish review and the page at a gate.
- [Templates and Settings](/reference/web-ui/templates-and-settings): the Chains and Library screens and each Settings screen.
