The board lists every [work item](/concepts/vocabulary#work-item), grouped by what it needs from you. This page covers its groups, a row's button, the filters and the side panel.

![The Kraft board in the dark Ink look with a violet accent: filters for chain, gate and stop reason above work items grouped by status, Needs you first with each item's one button (Review at a gate, Retry, Raise cap, Answer, Resume and Raise budget on the stopped ones), and Running below it, with a Select all link on every group and a ? shortcuts button in the toolbar](/assets/board.png)

## The groups

| Group | What is in it |
|---|---|
| **Needs you** | A [gate](/concepts/vocabulary#gate) waits for your approval, an agent asked a question, the item stopped on a failure or a [cap](/concepts/vocabulary#cap), or a person paused it mid-chain. Always first; **N NEED YOU** counts them |
| **Running** | An agent or a check is working on it |
| **Not started** | Filed paused and never started, or waiting on another item before its first node |
| **Done** | Completed and cancelled items. **show all N** shows more than the five most recent |

## A row

A row shows the title, why it is where it is (`approve spec`, `failed at implementation`, `created paused`), the repo, the ID, the [chain](/concepts/vocabulary#chain) and when it last changed. The ticks on the right are the chain's [nodes](/concepts/vocabulary#node), filled in as the item moves along it. A row that needs something carries one button:

| The row says | It does |
|---|---|
| **Review** | Opens the review page at the waiting gate |
| **Answer** | Opens the side panel at the agent's question |
| **Raise cap** | For a time or attempts cap: opens the side panel's Config tab, where the panel's own **Raise cap** opens the editor |
| **Retry…** | For a failed item or a [stuck](/concepts/vocabulary#stuck) [fix loop](/concepts/vocabulary#fix-loop): opens the side panel, where **Retry** is |
| **Resume** | Resumes a paused item that has already started |
| **Raise budget** | For a dollar or token budget stop: opens the side panel at the editor or at a banner saying why it can't be raised |
| **Open** | Opens the side panel for any other stop |

A row that hasn't started has no button: start it from the side panel. For what each stop offers, see [Raise a cap on a stopped item](/guides/day-to-day/raise-a-cap#which-stop-offers-what).

An [in-place item](/guides/run/run-items-in-place) is marked **in your checkout**. One queued behind another in-place item says `waiting for the checkout: “<title>” is using it`.

## Filter, Group and Sort

| Control | What it does |
|---|---|
| **Filter by title or ID** | Narrows every group as you type |
| **Chain ▾** | Shows only items on one chain |
| **Gate ▾** | Shows only the items waiting at one gate, named by what it decides (`approve spec`) |
| **Stop reason ▾** | Shows only the items stopped for one reason: `gate`, `question`, `cap`, `budget`, `failed`, `conflict`, `MR closed`, `config`, `infra`, `stuck` or `checkout` |
| **all repos ▾**, beside **Board** | Shows only one repo |
| **Group** | **Status** (the default), **Repo** or **Chain**; **Needs you** comes first in all three |
| **Sort** | **Needs attention**, **Recently updated**, **Created** or **Title**, within a group |

The filter, group and sort are in the page address, so a shared link opens the same view. The [Analytics](/reference/web-ui/analytics) gate and stop-reason rows open the board filtered this way. When a filter leaves nothing, **Clear** drops the filters.

## Selecting several items

Tick a row's checkbox to select it. A bar at the bottom acts on the selection. Each button counts only the selected items that take it, and an item that refuses is listed with the server's reason.

| Button | What it does |
|---|---|
| **‖ Pause N** | Pauses the running items |
| **Resume N**, **Retry N** | Resumes the paused items that have begun; retries the stopped ones |
| **Cancel N…** | Cancels every item that hasn't ended, after asking for a reason that goes into each run log. **Undo** takes it back for a few seconds |
| **Archive N** | Archives the completed or cancelled items |
| **Clear** | Drops the selection |

**Select all** on a group's header selects the items the group is showing, so on **Done** it is only the newest few until you choose **show all N**.

## Archived items

The **Done** header's link, **Archived · auto-archive after 30 days**, opens **Archived** at `/archived`. The number is `archive.after_days` in [`policy.yaml`](/reference/configuration/policy). The list has its own filter and sort; **Restore** on a row puts the item back on the board, and **Restore N** does so for ticked rows.

## The side panel

Select a row and a panel opens on the right without leaving the board. It has three tabs:

| Tab | What it shows |
|---|---|
| **Overview** | The state card with what the item waits on and the buttons to act: approve, answer, retry, raise a cap, escalate. A stuck fix loop's card offers **Retry from** a task and **Escalate…** |
| **Activity** | Every event on the item, newest first. Select an event about a node to open that node |
| **Config** | The limits the item runs under and anything changed for this item alone. The pencil beside **Budget** edits the item's dollar cap |

The bottom of the panel holds the item's main action, the same as the item page's header. **Open item ↗** opens the full page. To skip the panel, hold **⌘** (**Ctrl**) and select a row, or set **Settings › Board & code › Board › Open items in** to **Full page**. Shortcuts are on [Sidebar, search and keyboard](/reference/web-ui/sidebar-search-and-keyboard#keyboard-shortcuts).
