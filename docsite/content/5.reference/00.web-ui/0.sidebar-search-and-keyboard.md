This page holds what every screen of the web UI shares: the sidebar, search, vector search and the keyboard shortcuts. For what a [work item](/concepts/vocabulary#work-item), chain, node and gate are, see [Vocabulary](/concepts/vocabulary).

## The sidebar

The sidebar on the left reaches every page.

| Entry | What it opens |
|---|---|
| **Search** (**⌘K**, or **Ctrl+K**) | A search box over any page. See [Search](#search). |
| **Board**, **Analytics** | The work items by what they need from you, and the [Analytics](/reference/web-ui/analytics) page. |
| **Templates** | Chains and Library. |
| **Settings** | Repos, Harnesses, Policy, Auto-intake, Notifications, Access, Appearance, Board & code, Storage and About. |
| The version, at the foot | **About**. **update** beside it appears when a newer Kraft is available, and **restart** when an installed update waits on a restart. |

The sidebar starts pinned open. The button in the top-left corner (**⌘\\**, or **Ctrl+\\**) unpins it, and the sidebar then opens over the page when you point at the button. Collapsed, the button carries the Board's dot when something needs you. Your choice is kept in the browser.

## The offline banner

_Added in 2.1_

When the board can't be read, or the live connection to the server drops, a red banner opens across every page: **Offline**, then what broke. What the page shows may be out of date, and changes are off until Kraft reconnects. **Retry now** reads the board again at once; Kraft also reads again by itself when the connection returns.

| The word beside **Kraft** | It means |
|---|---|
| **live** (green) | Connected |
| **connecting…** (grey) | The page is opening and nothing has failed |
| **offline** (red) | A read failed |
| **reconnecting…** (red) | A dropped connection is coming back |

## Search

**Search** finds work items, documents, issues in [beads](/concepts/vocabulary#beads) and pages.

- An item waiting at a gate shows under its own name with the gate (**approve spec**) after it, and opens straight onto that gate's review.
- **Match** switches between **Hybrid**, **Keywords** and **Meaning** (the phone's **Match by**).
- A document opened from a search shows the matches in it; **↑**/**↓** step through them.
- **Filters** narrows the documents.

## Vector search

To add semantic matching to a uv or script install, see [Add vector search](/guides/run/upgrade-kraft#add-vector-search).

## Keyboard shortcuts

The shortcuts the web UI has, by screen. Keys that work as in any form, such as **Tab**, or **↵** in a one-line box, are listed only where a screen adds a rule. **⌘** is the Mac key; on any other keyboard use **Ctrl** in its place, and the web UI prints the one your keyboard has. A shortcut marked "outside a box" doesn't fire while the cursor is in a box that takes text.

### Everywhere

| Keys | Where | What it does |
|---|---|---|
| **⌘K** | Every page, with the cursor in a box too | Opens [search](#search). |
| **⌘\\** | Every page, outside a box | Pins the sidebar open, or unpins it. |
| **?** | Every page, outside a box and with no dialog open | Opens the list of shortcuts: these first, then the ones of the page you are on. The **?** button beside **Sort** on the board does the same. |
| **⇧N** | Every page, outside a box and with no dialog open | Opens the board's new work item box, keeping the board's filters. Off while the server is unreachable. |
| **Esc** | The sidebar, while it is unpinned | Gives focus back to the page, which hides the sidebar. |
| **↑**, **↓**, **↵**, **Esc** | Search | **↑**/**↓** move through the results and stop at the first and the last, **↵** opens the highlighted one, **Esc** closes search. |
| **⌘↵** | A box you write a [steer](/concepts/vocabulary#steer), an answer, a note, a reason or a comment in | Sends it, as its button would, once the button is enabled. **↵** starts a new line. |
| **←**, **→**, **Home**, **End** | A row of tabs, such as the tabs in search | Moves to the previous, next, first or last tab, and selects it. |
| **←**, **→**, **↑**, **↓**, **↵**, **⌘↵** | A focused node in a chain graph | The arrows move between the steps and between the tasks in a step. **↵** opens the node, and **⌘↵** expands it. |
| **←**, **→**, **Home**, **End** | A pane's resize handle | **←** widens the pane and **→** narrows it. **Home** and **End** set its smallest and largest width. |

### Board

| Keys | Where | What it does |
|---|---|---|
| **/** | The board, outside a box | Moves the cursor to **Filter by title or ID**. |
| **↑**, **↓**, **j**, **k**, **Home**, **End** | The board, on a row | Moves to the row above or below, or to the first or last row, across groups. The list is one **Tab** stop, so **Tab** leaves it from the row you were on. _Added in 2.1_ |
| **g** | The board, outside a box | Moves to the first row under Needs you. _Added in 2.1_ |
| **a** | The board, on a row | Runs the row's button (**Resume**, **Review**, **Retry…**). A row with no button ignores it. _Added in 2.1_ |
| **Space** | The board, on a row | Selects or clears the row, to [select several items](/reference/web-ui/board#selecting-several-items). |
| **⌘↵** | The board, on a row | Opens the item's full page instead of the side panel. |
| **↵** | The board, on a row | Opens the item in the side panel. |
| **Esc** | The board, with the side panel open | Closes the [side panel](/reference/web-ui/board#the-side-panel). |
| **Esc** | The board, with rows selected and no side panel | Clears them. In the cancel box on the selection bar, **Esc** closes the box and keeps the selection. _Added in 2.1_ |
| **Esc** | The new work item box, and the new-item page | Closes it. If you typed a title or a brief, or designed a one-off chain on the page, it asks before it throws them away. |

### Item page

| Keys | Where | What it does |
|---|---|---|
| **Esc** | An item's page, with the cursor outside a box and no menu or dialog open | Steps back one level: what is open over the page, then the inspector, then a node view back to the chain. |
| **Tab**, **←**, **→**, **↵**, **↓**, **↑** | The [chain overview](/reference/web-ui/item-page#the-chain-overview) | **Tab** reaches it on the node the item is at. **←** and **→** move along it, **↵** centres the graph on that node, **↓** moves to the node on the graph and **↑** comes back up. |
| **↓**, **↵** | A task with sub-agents | **↓** from the task reaches its sub-agent marks, and **↵** opens the mark in the inspector. |
| **↵**, **Esc** | The item's title, while you rename it | **↵** saves the new title, **Esc** keeps the old one. |

### Review page

| Keys | Where | What it does |
|---|---|---|
| **Esc** | The review page, outside a box and with no menu or dialog open | Goes back to the item's chain. |
| **↑**, **↓**, **Shift+↑**, **Shift+↓** | The review page, on a file's lines | Picks the line above or below, or extends the pick to it on the same side. |
| **Alt+Shift+↑**, **Alt+Shift+↓** | The review page, on a file's lines | Extends the pick one line at a time across sides, a removed line and then its replacement. _Added in 2.1_ |
| **Tab** | The review page, from a file's lines | Reaches the picked line's **+**. |
| **c**, **↵** | The review page, with a line picked | Opens the comment box on the pick. |
| **]**, **[** | The review page, outside a box and with no dialog open | Goes to the next or previous [unresolved thread](/reference/web-ui/review-page#unresolved-threads), as the toolbar's arrows do. _Added in 2.6_ |
| **n**, **p** | The review page, on a file's lines | Moves to the next or previous file's lines. |
| **Esc** | A comment box on the review page | Cancels the comment. If you wrote something, it asks first. |

### Templates and Settings

| Keys | Where | What it does |
|---|---|---|
| **⌘Z** | Chains, Library and the Repos, Harnesses, Policy and Auto-intake screens, outside a box | Undoes the last change to the draft. |
| **⌥←**, **⌥→** | Chains and Library, outside a box | Moves the selected node, or the selected step in a node view, one place earlier or later. |
| **F2** | The Library pane, outside a box | Renames what the pane shows. |
| **/** | The Library list, outside a box | Moves the cursor to the list's filter. |
| **Esc** | Repos, Harnesses, Policy and Auto-intake, outside a box | Leaves **Review & publish**, then the YAML view. |
| **Esc**, **Tab** | A YAML editor | **Esc** leaves the editor. **Tab** indents two spaces, and **Shift+Tab** leaves it. |
| **↑**, **↓**, **Home**, **End** | The bottom pane's resize handle in Chains and Library | **↑** makes the pane taller and **↓** shorter. **Home** and **End** set its smallest and largest height. |

### Menus and dialogs

| Keys | Where | What it does |
|---|---|---|
| **Esc** | A dialog, menu or card | Closes it. One that holds text you typed stays open: use its **Cancel**. |
| **↑**, **↓**, **Home**, **End** | An open menu | Moves between its entries. **Tab** closes the menu. |
