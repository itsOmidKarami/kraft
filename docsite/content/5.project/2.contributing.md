title: Contributing

---

The contributor guide lives in the repository so it stays next to the code it
describes: [CONTRIBUTING.md](https://github.com/itsOmidKarami/kraft/blob/main/CONTRIBUTING.md).
It covers:

- setting up a dev environment with `just setup` and `just dev`
- running tests through `just test` (never raw `pytest`) and the testing rules in `docs/testing.md`
- the release label every pull request needs, and its `## Changelog` section
- which docs page to update when you change a command, config field, or tool

Maintainers cut releases as described in
[RELEASING.md](https://github.com/itsOmidKarami/kraft/blob/main/RELEASING.md).
