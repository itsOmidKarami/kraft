---

The contributor guide lives in the repository so it stays next to the code it
describes: [CONTRIBUTING.md](https://github.com/itsOmidKarami/kraft/blob/main/CONTRIBUTING.md).
It covers dev setup, tests, the release label every pull request needs, and
which docs page to update when you change behaviour.

Maintainers cut releases as described in
[RELEASING.md](https://github.com/itsOmidKarami/kraft/blob/main/RELEASING.md).
