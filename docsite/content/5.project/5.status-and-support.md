## Maturity

Kraft is young. One maintainer builds it, it reached 1.0 in September 2026,
and it changes quickly. Expect rough edges, and read the release notes
before you upgrade.

## Versioning and stability

Kraft follows semantic versioning. These are its public interfaces:

- the `kraft` command line: its verbs, flags and `--json` output;
- the HTTP endpoints meant for other programs: `POST /api/triggers` and
  `GET /api/health`;
- the YAML config schema under `$KRAFT_HOME/templates`;
- the MCP tools.

Every other HTTP route exists for the board and can change in any release.

| Release | May change |
|---|---|
| Major (`2.0.0`) | Anything, including a breaking change to the CLI, the API, the config schema or the state on disk. The release notes say what breaks and how to move. |
| Minor (`1.2.0`) | New capabilities that do not break an existing one. |
| Patch (`1.1.1`) | Fixes to something that already shipped. |

Only the latest release gets fixes, security fixes included. Kraft has no
long-term support branch. `kraft admin update` installs the latest release.

## Supported platforms

- **macOS and Linux.** Windows is not supported, and WSL is untested.
- **Python 3.14.** uv installs it for you.
- **Docker or Podman,** only if you use the optional
  [sandbox](/reference/configuration/repos#sandboxed-workers).

## Getting help

Ask questions and report bugs in
[GitHub issues](https://github.com/itsOmidKarami/kraft/issues). Report a
security problem privately instead; see
[SECURITY.md](https://github.com/itsOmidKarami/kraft/blob/main/SECURITY.md).
