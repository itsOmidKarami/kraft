Plan: config loader migration
planplan · written 09:12repo-a/.engineering/plans/config-loader.mdindex 2 min behind git
Default editor is set in Settings → General.

Goal

Replace the ad-hoc dict loader in kraft/config.py with a schema-validated loader so that invalid config fails at startup with a path-qualified error instead of at first use.

Steps

  1. Define ConfigSchema mirroring the current YAML shape; keep field names.
  2. Load, validate, then freeze; expose load_config(path) -> Config.
  3. Map validation errors to ConfigError(path, message).
  4. Migrate callers; delete the old get() accessor.

Verification

uv run pytest tests/test_config.py -q
uv run kraft --config fixtures/bad.yaml   # expect ConfigError: repos[1].path
