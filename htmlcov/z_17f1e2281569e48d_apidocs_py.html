1"""`/docs` (Swagger UI) and `/redoc` (ReDoc), FastAPI's own pages with their 

2scripts pinned. 

3 

4FastAPI's defaults load `swagger-ui-dist@5` and `redoc@2` from jsdelivr: a 

5major version, whatever its newest release is that day, with no integrity 

6check. The pages need no login and run as Kraft's own origin, so a bad 

7release of either would hold the whole API, which on a loopback bind needs no 

8login either. Here each asset is one exact release, and the browser refuses 

9it unless it hashes to what is written below. 

10 

11To move to a newer release, change its version and recompute every hash for 

12it, from the file inside the package's npm tarball (jsdelivr serves those 

13bytes unchanged): 

14 

15 openssl dgst -sha384 -binary package/swagger-ui-bundle.js | base64 

16"""

50def _with_integrity(page: HTMLResponse) -> HTMLResponse: 

51 """`page` with an `integrity` on every pinned asset it loads, and no image 

52 from another site. FastAPI's page builders take a URL but no attributes 

53 for it, so they are added to the tag the URL sits in. `crossorigin` is 

54 what lets the browser check a hash on a file from another origin at 

55 all.""" 

56 html = page.body.decode() 

57 for url, digest in INTEGRITY.items(): 

58 html = html.replace(f'"{url}"', f'"{url}" integrity="{digest}" crossorigin="anonymous"') 

59 return HTMLResponse(html, headers={"content-security-policy": CONTENT_SECURITY_POLICY})
