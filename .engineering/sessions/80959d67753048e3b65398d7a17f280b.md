## Investigation into the `on.test.run` failure

`on.test.run` runs the full suite (`uv run pytest -q`). It reported 7
failures, all in `tests/test_cli_doctor.py`:

- `test_hooks_check_names_a_hook_left_on_noop`
- `test_hooks_check_names_a_hook_missing_from_the_live_registry`
- `test_every_config_check_reports_even_with_no_templates_dir`
- `test_hooks_check_is_skipped_without_a_bundled_registry`
- `test_completion_check_is_skipped_outside_zsh`
- `test_completion_check_names_the_missing_eval_line`
- `test_completion_check_passes_once_registered`

All fail with `ValueError: kraft 401: authentication required` from
`doctor._mcp_check` calling `client.repos()`. Root cause: these particular
tests don't use the `app` fixture (`tests/conftest.py`), which is what
monkeypatches `client.http` onto an in-process ASGI transport. Without it,
`client.health()`/`client.repos()` make a real HTTP call to
`base_url()` — host/port default to `127.0.0.1:8765` (the hardcoded default
in `src/kraft/config.py`) unless `KRAFT_HOST`/`KRAFT_PORT` are set, and the
autouse `_isolated_kraft_home` fixture doesn't touch those. On this
particular machine a real `kraft admin start` is listening on that same
default port `8765`, so `client.health()` succeeds against the live server
instead of raising `ConnectError` (the path these tests are written to hit),
and the subsequent `client.repos()` call 401s against real auth instead of
being skipped.

Confirmed this is unrelated to Kraft-mxdx: checked out the parent commit
(`99a05ae^`) in a throwaway worktree and ran the same `test_cli_doctor.py`
subset — identical 7 failures. `src/kraft/doctor.py` and
`tests/test_cli_doctor.py` are untouched by this work item's diff. This is a
pre-existing test-isolation gap (these tests assume no server on the default
port) colliding with a real `kraft admin start` this dev machine happens to
be running, not a defect introduced or reachable from the Kraft-mxdx change.

Left as-is per "make no unrelated changes" — fixing `test_cli_doctor.py`'s
port isolation is out of scope for this work item.
